# W20 original boss audiovisual provenance

All files in `assets/runtime/w20/` and the deterministic boss-audio synthesis definitions in `game/audio/boss_audio_catalog.gd` are original project-authored work created for LANTERNFALL W20. No third-party images, fonts, samples, sound libraries, model outputs, or externally licensed media are embedded in these W20 assets.

The SVG files are editable source/runtime vectors. The audio source is the explicit synthesis parameter table and PCM renderer in Git; runtime audio is generated from that source. This record does not waive the later human quality gate and does not advance `implemented_content.bosses` by itself.
