# W24 Original Audio Provenance

All W24 production-audio identities are authored in this repository as deterministic procedural synthesis and mapping code.

Authoritative runtime sources:
- `game/audio/production_audio_catalog.gd`
- `game/audio/production_audio_synth.gd`
- `game/audio/audio_director.gd`
- retained project-original `game/audio/boss_audio_catalog.gd`
- retained project-original W14 system cues in `game/audio/representative_audio_library.gd`

Runtime integration source:
- `game/ui/main_shell_w24.gd`
- `game/ui/main_shell.tscn`

No external samples, stock music, commercial sound libraries, copied melodies, downloaded WAV files, or model-generated audio binaries are included. The Git history of the source files above is the provenance record.

W24 CI WAV files are generated listening evidence only. They are not authoritative runtime source assets and do not create third-party license obligations.
