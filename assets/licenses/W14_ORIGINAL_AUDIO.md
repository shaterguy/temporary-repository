# W14 Original Audio Provenance

All W14 representative audio is authored inside this repository as deterministic procedural synthesis code. No external samples, stock music, commercial sound libraries, copied melodies, downloaded WAV files, or model-generated audio binaries are included.

Runtime source:
- `game/audio/audio_catalog.gd`
- `game/audio/audio_music_synth.gd`
- `game/audio/audio_sfx_synth.gd`
- `game/audio/representative_audio_library.gd`
- `game/audio/audio_director.gd`

The Git history of those files is the provenance record for the W14 audio identities. CI review WAV files are generated evidence and are not authoritative source assets.
