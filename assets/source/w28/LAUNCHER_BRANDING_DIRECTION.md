# W28 launcher branding direction

Scope: `res://assets/branding/launcher_*.svg`
Milestone: W28 Android production packaging repair

## Visual grammar

- Preserve the established W13 contrast: cold twilight navy/steel fields surrounding one warm lantern-gold allied focal light.
- The launcher mark combines the Ark's wide armored silhouette with a centered lantern core so the product remains recognizable at small icon scale.
- Main artwork is a 512×512 square composition. Adaptive foreground keeps all critical Ark/lantern geometry inside the central safe area; adaptive background carries only noncritical twilight/horizon fields. A monochrome glyph preserves the same silhouette for Android themed icons.
- No text, font dependency, stock mark, external logo, generated brand asset or Godot engine branding is used.

## Authorship

All four launcher SVG files were authored directly for LANTERNFALL in this repository on 2026-09-10 as project-original vector artwork. They derive only from the project's own W13 visual grammar and shapes and incorporate no third-party art file.
