# W23C world/event art direction

Task: `SR-20260909-150106-PPO12Y`

W23C continues the established LANTERNFALL visual grammar rather than introducing a new style system. Cold twilight blues, mineral teal, soot violet and eclipse purple define hostile space; warm lantern amber is reserved for readable interaction, life, signal and critical focal points. Dark outer strokes keep silhouettes legible against the existing environment vectors.

## Enemy breadth

- The production target is thirty tracked general-enemy visual roles across five parent regions, six per region.
- Twilight Shipyard promotes six existing project-original W13 identities (`dusk_mite`, `rivet_hound`, `glasswing`, `chain_wraith`, `ballast_guard`, `hull_reaver`) into the W23C production mapping. The W13 `emberling` and `lantern_leech` remain representative encounter variants and are not used to inflate the thirty-role target.
- Glass Garden, Flooded Archive, Ash Railway and Eclipse Fortress receive twenty-four new authored vector silhouettes in `enemy_behavior_atlas.svg`, one frame for each existing W18/W19 `behavior_id`. Their geometry follows the disclosed role: skaters and flankers read laterally, wardens and anchors read as broad blocks, pursuit forms read forward, and phase-oriented forms keep asymmetrical shadow cues.
- W23C does not change behavior parameters, health, damage, spawn cadence, phase logic or doctrine logic.

## Choice-event illustration

- All forty W21 events receive a dedicated 240×135 frame in `choice_event_atlas.svg`.
- Each parent region retains a consistent environmental motif while every event frame has a different focal composition keyed to its authored event subject: dock signal/chain/roster/chart/retreat light/crane/wave/table; flower/seed/prism/door/water grid/overheated prism/route/shelter; records/diver/map/gate/failure log/lifeline/trace/vault; rail priority/engine/ticket/ember car/wreck/boiler/memorial/storm; eclipse observation/gate/map/archive/cracked window/closing gate/loop/survivor signals.
- Event art is presentation-only. The two choices, persistent story flags, next-expedition modifiers and ending biases remain exactly the W21 data contract.

## Region production review

The five existing project-original environment vectors from W13, W18 and W19 remain the actual expedition backgrounds. W23C tracks all five in one production-art manifest and includes them in the review sheet rather than replacing already integrated environments solely to create new files.

## Readability and state rules

- The hub event card is non-interactive and never becomes a new input target.
- It is shown only while a story event is pending and is cleared before expedition presentation.
- Combat danger telegraphs and boss warnings remain authoritative over decorative art. Enemy art is bounded around the existing collision body; health and warning semantics stay independent from texture shape.
- 1280×720 automated review captures are evidence generation only. Human visual acceptance remains pending until W23D review.

## Provenance

All new W23C geometry is project-original SVG authored for this repository from vector primitives. No external stock art, generated third-party asset pack, font file, trademarked character, embedded raster image or licensed external texture is included.
